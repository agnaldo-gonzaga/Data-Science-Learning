# 🐍 02-Python | Análise e Ciência de Dados
## 📌 Sobre
Este diretório representa minha trilha de especialização em Python, focada em transformar dados brutos em insights acionáveis.
Aqui documento desde fundamentos da linguagem até técnicas avançadas de:
- Manipulação e transformação de dados
- Análise exploratória (EDA)
- Visualização de dados
- Automação de pipelines

## 🎯 Objetivo
Demonstrar:
- Proficiência nas principais bibliotecas do ecossistema de dados
- Capacidade de análise aplicada ao negócio
- Resolução de problemas com código limpo e eficiente

## 🛠️ Tecnologias e Ferramentas
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook
- Scikit-learn

## 📂 Estrutura de Estudos

### 📊 Manipulação e Transformação de Dados
- **Pandas — Fundamentos**
  - Criação e leitura de DataFrames
  - Seleção, filtragem e ordenação
  - Tratamento de nulos
- **Pandas — Pivot & Transformação**
  - `pivot_table` com múltiplas agregações
  - `melt`, `stack`, `unstack`
  - `crosstab` e `transform`
  - Comparação vendas × meta
- **NumPy**
  - Operações vetorizadas
  - Arrays multidimensionais
  - Funções matemáticas e estatísticas

### 📈 Análise Exploratória (EDA)
- **Estatística Descritiva**
  - Médias, medianas, desvio padrão
  - Distribuições e outliers
- **Agrupamentos e Métricas**
  - `groupby` com múltiplas funções
  - Segmentação de dados
  - Ranking e percentuais
- **Qualidade de Dados**
  - Identificação e tratamento de nulos
  - Detecção de duplicatas
  - Tipagem e conversão de colunas

### 🎨 Visualização de Dados
- **Matplotlib**
  - Gráficos de linha, barra e dispersão
  - Customização de layouts
- **Seaborn**
  - Heatmaps e correlações
  - Distribuições e boxplots
  - Paletas e estilos

## 🚀 Destaques de Evolução
- Padronização de notebooks com cabeçalhos e comentários
- Evolução de scripts simples para pipelines estruturados
- Foco em código legível, reutilizável e bem documentado
