# 🗄️ 01-SQL | Manipulação e Inteligência de Dados

## 📌 Sobre
Este diretório representa minha trilha de especialização em SQL, focada em transformar dados brutos em informações estratégicas.

Aqui documento desde fundamentos da linguagem até técnicas avançadas de:
- Análise de dados
- Otimização de queries
- Modelagem de banco

Demonstrar:
- Proficiência em diferentes dialetos SQL
- Capacidade de análise aplicada ao negócio
